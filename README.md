# QRISK3-2017

Open source implementation of the QRISK3-2017 cardiovascular disease risk prediction algorithm, released by Endeavour Predict CIC.

## About

QRISK3 is a clinical risk prediction algorithm used to estimate an individual's risk of developing cardiovascular disease (CVD) over the next 10 years, based on risk factors such as age, sex, ethnicity, smoking status, blood pressure, cholesterol ratios, and various medical history and treatment variables. It is widely used in UK primary care and clinical software.

This repository contains source code intended to faithfully implement the QRISK3-2017 algorithm as published at [qrisk.org](https://qrisk.org).
